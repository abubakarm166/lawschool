================================================================================
DATABASE CHANGES
================================================================================

NEW MODELS:
-----------
1. UserProfile
   - Links Django User to extended profile
   - Manages registration requests and approvals

MODIFIED MODELS:
----------------
1. Assignment
   - Added: description field (TextField, optional)
   - Added: created_at field (DateTimeField, auto)
   - Added: download_count() method

2. Download
   - Complete redesign:
     - Now links User and Assignment (Foreign Keys)
     - Added: user (ForeignKey to User)
     - Added: assignment (ForeignKey to Assignment)
     - Added: downloaded (BooleanField)
     - Added: downloaded_at (DateTimeField, auto)
     - Added: ip_address (CharField)
     - Added: unique_together constraint (user, assignment)
   - Removed: opened, currentURL, Download fields

================================================================================
FUNCTIONALITY CHANGES
================================================================================

REMOVED FUNCTIONALITY:
----------------------
- Unique URL paths (/1, /2, /3, etc.)
- URL-based user tracking
- Direct assignment access without login
- Simple download tracking without user association

ADDED FUNCTIONALITY:
--------------------
- User registration request system
- Admin approval workflow
- User authentication (login/logout)
- User-specific download tracking
- Assignment management in admin
- Download statistics in admin
- Single shared URL for all users
- IP address tracking
- Registration request management in admin
- Bulk approve/reject actions

WORKFLOW CHANGES:
-----------------
OLD WORKFLOW:
1. Admin creates unique URLs (/1, /2, /3, ...)
2. Admin sends unique URLs to students
3. Students click on their unique URL
4. System tracks clicks by URL

NEW WORKFLOW:
1. User requests registration (single shared URL)
2. Admin approves registration
3. User logs in
4. Admin creates assignments
5. Users view assignments (same URL for all)
6. Users download assignments
7. Admin views download statistics per assignment

- Timestamp tracking

- Better admin interface with statistics
- Error handling and validation
- User-friendly messages and notifications

================================================================================
MIGRATION REQUIREMENTS
================================================================================

IMPORTANT: You must run migrations before using the new system:

1. python manage.py makemigrations
2. python manage.py migrate

This will:
- Create UserProfile table
- Modify Assignment table
- Completely recreate Download table structure

NOTE: Existing download data will be lost during migration due to model changes.
If you have important data, back it up first.
